Why this route?

AI Math Assistant starts with an exact local solver. Supported formulas are parsed with a bounded grammar, solved symbolically, and checked before any optional model request.

1

Compute locally
Derivatives, integrals, limits, and polynomial roots use the deterministic route.

2

Show evidence
The answer includes the verification status, solution steps, and measured route details.

3

Call AI only when asked
Explain and fallback actions are explicit, separate, and labeled unverified.

The interface reports model calls, provider-reported tokens, and latency when available. It does not claim energy, FLOPs, or universal speedups.
